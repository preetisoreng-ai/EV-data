# EV intro video — three storylines

Content: `../content.json` v1 (locked). Look: Poppy design language (`../../design/poppy-design-language.md`):
cream paper `--pp-paper`, serif headline, crimson `--pp-crimson` on the one number per beat, poppy red marks,
rose/sand context. (The spec's "cream paper + serif" default ban does not apply: it is this brand's own material.)
Output: 1920x1080 master + 1080x1350, 1080x1080, 1080x1920; 30 fps; 36–42 s.
Cover rule: frame 0 = title + 90.6M + five poppies fully drawn (`cover_insight: fleet`).

## A. The field rebuilds ← recommended (one object carries every number, so the story stays one picture)

- **Device / form:** a number lands · one frame that rebuilds. The five poppies never leave; they rearrange into each chart.
- **Sees and feels:** a poster-still opening that comes alive; each insight is the same field reshaped, so the viewer feels the fleet's shape rather than reading cards.
- **First 2 s:** frame 0 is the composed poster (title, "90.6M vehicles in the supplied World total", five poppies on the ground line). At 0.3 s the poppies sway once and the 90.6M count settles; nothing enters from blank.
- **Beats:** cover/hook 90.6M → China's poppy swells to 57.2% while the others shrink to seeds → poppies line up by rank with labels (77.7% top five) → stems lie down into the rolling 12-month bars (China 58.3% crimson) → bars collapse into one line: min/median/max dots, "4.2× spread" → petals fall, leaving "Fleet counts show where EVs are concentrated." → end card: poppy mark, landing URL.
- **Look:** cream paper, serif title, sans numbers 800, crimson one number per beat, rose/sand context, dotted gridlines.
- **Sound:** soft piano + light strings bed (free library track), a paper-rustle tick when the field rearranges, a low chime on 57.2% and the end card.

## B. Walk the poster

- **Device / form:** the result first · one continuous take. The finished infographic is the world; the camera travels it.
- **Sees and feels:** the whole poster at frame 0, then the camera glides panel to panel, each panel animating as it is reached, and pulls back to the full poster.
- **First 2 s:** full poster still (cover); at 1.2 s the camera begins a slow push toward "90.6M".
- **Beats:** full poster → 90.6M → 57.2% → poppy chart blooms → sales bars → oil spread → evidence line → pull back to full poster + URL.
- **Look:** identical to the infographic (same file family), a 35 mm-style slow camera, no cuts.
- **Sound:** ambient pad, page-turn swish at each stop.

## C. One hundred seeds (bold)

- **Device / form:** a number lands · endless zoom.
- **Sees and feels:** the fleet as 100 seeds; 57 turn crimson and grow into one giant China poppy; the camera dives into its dark centre, which opens onto the next chart, again and again.
- **First 2 s:** frame 0 shows the title, 90.6M and the five poppies (cover), which dissolve into 100 seeds at 1.5 s.
- **Beats:** cover → 100 seeds, 57 crimson (57.2%) → seeds sprout, five poppies ranked (77.7%) → dive into China's centre → sales bars inside → dive → oil dot plot → zoom out to the field + evidence line → end card.
- **Look:** same palette; deeper scale changes, more camera.
- **Sound:** pulse-led bed, a whoosh on each dive.
